# Security policy

SkillCheck is a local static scanner. It does not execute a skill, but a finding is not a guarantee that a skill is safe. Review the source and permissions before installing or running any third-party skill.

## Reporting a vulnerability

Do not open a public issue with an exploitable proof of concept. Contact the maintainers privately with:

- the affected version;
- a minimal reproduction or skill archive;
- the expected and observed behavior; and
- any suggested mitigation.

Use [GitHub's private vulnerability reporting form](https://github.com/ECHOQWETVG/skillcheck/security/advisories/new).
